# Bakez Bitz Bakery Website

A responsive front-end bakery storefront featuring product categories, search, sorting, a demonstration cart, reviews, merchandise, and a contact section.

## Features

- Responsive navigation and mobile menu
- Search across cakes, pastries, beverages, and merchandise
- Product sorting by price and name
- Interactive shopping cart with quantity totals
- Product gallery, testimonials, and contact section
- Responsive layouts for desktop, tablet, and mobile screens

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Demo limitations

This is a front-end demonstration. Checkout and contact submission do not process payments or transmit data to a server.
